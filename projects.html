My Projects

Here are some projects and assignments I've worked on in school and on my own.

Python Calculator

For my Intro to Programming class, I built a basic calculator using Python. The software I really liked was PyScripter because it helped a lot with syntax suggestions since it was an introductory course. The calculator handled basic math functions such as addition, subtraction, multiplication, and division. I also added error handling so the program shows an "error", or something like "invalid" instead of crashing when the user tries to divide by zero. The project taught me the basics of user input, conditions, and handling errors.

Mortgage Calculator

In my Business Analytics course I built a calculator that is very useful for the average household. In the course we learnt the many different functions of Microsoft Excel. Using them, I created a mortgage calculator which takes a couple different inputs such as term, down payment, interest rate, and loan amount to give an output of monthly payment, total paid over the loan, and total interest paid. This calculator personally helped when comparing different potential payments and interest rates from banks when shopping around for a mortgage. To create the calculator one of the main functions I used was the PMT function.

Auto Loan Calculator

Business Analytics taught me how to create an auto loan calculator using the PMT function as well as NPER. I also used basic functions such as the different lookups (V,X) to pull up interest rates from a table based on credit score. I had inputs for credit score, purchase price, and payment term. I also modified the calculator to make a lease version which adds an input for the residual value of the vehicle.

Entertainment Room Mesh Network

In my basement at home I have an entertainment room set up. For that room I completed a mini project in order to have the best experience possible whenever I have guests over and we are using that room. I set up a separate network using a TP-Link Deco mesh system. Before buying the system I researched forums online where people with similar setups shared what system they chose and the pros/cons, which helped me narrow down the brands and level of system I was considering. Only the entertainment devices such as the TV, PlayStation, Alexa, smart lights, and surround sound connect to this network, while phones and other devices stay on the main one. Having this setup keeps network traffic low which gives the devices I have the best possible speeds.
